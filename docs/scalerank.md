# ScaleRank（方向性A）: 守るスケールを指定できる順位保存

試作のための定式化メモ。実装は `src/drbench/proto/scalerank.py`。

## 動機

- t-SNE / UMAP は「局所」、PCA / MDS は「大域」に強く、どのスケールを守るかは各手法の内部に暗黙に埋まっている。
- drbench の R_NX(K) 曲線で見ると、K≈10 では t-SNE、K>50 では MDS/PCA が勝つ。全スケールで勝つ手法はない。
- そこで「どのスケールの近傍構造を守りたいか」を **スケール分布 p(K)** として明示的に受け取り、それを直接最適化する。

## 目的関数

点 i と近傍サイズ K に対し、元空間での上位 K 近傍を N_K(i) とする。
低次元で「本当の K 近傍が、K 近傍でない点より近くにある」確率

  A_K(i) = P_{j ∈ N_K(i), m ∉ N_K(i)} [ d_Y(i,j) < d_Y(i,m) ]

は、K 近傍の所属を低次元距離で当てる分類の ROC-AUC。A_K(i)=1 なら低次元の K 近傍は元空間と一致する（R_NX(K) の滑らかな代理）。

目的関数:

  L(Y) = Σ_i Σ_K p(K) · (1 − A_K(i))

**スケール分布** p(K) ∝ K^(−γ)（K = 1..N−2）が基本の 1 ノブ:

| γ | 意味 |
|---|---|
| 1 | AUC_RNX と同じ 1/K 重み（局所寄り）|
| 0 | 全 K 一様（大域寄り、2022年の Q スコア＝footrule に近い）|
| 間 | その中間 |

オプションで帯域 p(K) ∝ (1/K)·exp(−(ln K − ln K0)² / 2s²) も指定できる（「K0 前後のスケールだけ守る」）。

### 三つ組の重み

K を p から引き、j を N_K(i) から、m を補集合から一様に引くと、三つ組 (i,j,m) の重みは

  ω_i(j,m) = Σ_{K = r(j)}^{r(m)−1} p(K) / (K (N−1−K))

（r は元空間での順位）。順位 r(j) と r(m) の間にある全スケールの重みの和になる。
「どの三つ組がどのスケールで効くか」が p(K) から導出される点が、TriMap（距離ベースの経験的な重み）との違い。

### 滑らかな代理

指示関数を Student-t 核 q = 1/(1+d²) の比で置き換える:

  ℓ(i,j,m) = −log( q_ij / (q_ij + q_im) ) = softplus( log(1+d_ij²) − log(1+d_im²) )

上に有界で、正しく並んだ三つ組の勾配は 1/(1+d²) で減衰するので、埋め込みが際限なく膨張しない。

### 負例の選び方（試作で追加）

素朴に m を補集合から一様に引くと、γ=1 でも R_NX@10 が t-SNE に届かなかった（digits 0.44 vs 0.58）。
既存手法の埋め込みをこの目的関数で採点すると ScaleRank 自身が最小値を取っていたので、最適化の失敗ではなく**代理の偏り**:
所属 AUC は「遠い非近傍がわずかに順位を間違える」ことも同じ重さで数えるが、R_NX(K) が気にするのは低次元の上位 K に**侵入してくる**点だけ。

そこで確率 `hard`（既定 0.3）で、m を「いま低次元で i の近く（上位 2K 以内）にいるが元空間では K 近傍でない点」から引く。
K が大きい（2K > `hard_k`=128）ときと、引いた点が真の近傍だったときは一様に戻す。低次元 kNN は 5 エポックごとに更新。
→ digits の R_NX@10 0.44 → 0.54、AUC 0.46 → 0.56。

## 最適化

- 毎エポック、各点を anchor として T 個の三つ組をサンプル（K ~ p → j, m）
- 勾配は解析的に計算し、点ごとの Adam で更新、学習率は線形に減衰
- 初期値は PCA（標準偏差を揃えてスケール）

## 試作の制約

- 元空間の全順位表（N×N int32）を持つので N ≲ 1万まで。大きい K の非近傍はランダムサンプル＋近似順位で置き換えられるはず（後回し）。
- NumPy 実装。速度は二の次。

## 検証したいこと

1. γ=1 で t-SNE 並みの局所指標（rnx@10, AUC_RNX）が出るか
2. γ=0 で MDS 並みの大域指標（dist_spearman, 大きい K の R_NX）が出るか
3. 中間の γ が、既存手法の「どれか 1 つ」よりも良いトレードオフ点を作れるか（パレートフロントの押し上げ）

## 最初の結果（2026-10-26, drbench 8データ × 3 seed）

- 局所（R_NX@10）× 大域（距離の順位相関）の平面で、ScaleRank の γ=1 / 0.5 / 0 はどのデータでも既存 7 手法のどれにも支配されない（`results/report/tradeoff.png`）。
- 例: pollen の γ=1 は R_NX@10 0.69（t-SNE 0.71）で距離相関 0.86（t-SNE 0.26、MDS 0.87）。
- γ を 1→0 に動かすと、局所↔大域のトレードオフ曲線をほぼ単調に移動する。

注意点:
- 純粋な局所指標（R_NX@10）の首位は全データで t-SNE のまま。差が大きいのは hier_blobs（0.24 vs 0.34）と density_blobs（0.31 vs 0.41）。
- AUC_RNX は γ=1 の目的関数と近いので、そこでの優位は割り引いて読む（2022年の Q スコアと同じ構図）。R_NX@10 と距離相関は直接は最適化していない。
- ハイパーパラメータは digits と pollen だけで調整した。
- 散布図では、クラスタのまわりに外れた点が散る（特に γ が小さいとき）。t-SNE ほど締まった見た目にはならない。
- 速度は NumPy 試作で 1.5〜12 秒（t-SNE の 2〜6 倍）、メモリは N² の順位表。

## 調査: 外れ点と blob での局所差（2026-10-26）

再現用: `scripts/diagnose_outliers.py`, `scripts/force_decomposition.py`, `scripts/score_under_objective.py --k0 10 --width 0.7`

### 外れ点（10-NN 半径が中央値の 3 倍超）

| データ | ScaleRank γ=1 | t-SNE |
|---|---|---|
| digits | 5.3% | 0.6% |
| pollen | 14% | 0.7% |
| hier_blobs | 23% | 0% |
| density_blobs | 22% | 0% |

1. **2 種類ある。** pollen の外れ点は元空間でも孤立している（10-NN 半径が中央値の 3.9 倍）ので、ある程度は忠実。hier_blobs の外れ点は元空間では普通の密度（1.06 倍）で、**手法が作った人工物**。
2. **人工的な外れ点は hard negative が作る。** hard=0 にすると hier_blobs 23% → 2%、density_blobs 22% → 4%。最適化手法（点ごと Adam / 全体共有 Adam / SGD）を変えても変わらない。
3. **外れるのは高次元の anti-hub。** 他の点の 10-NN にほとんど現れない点（N10 ≤ 2）。hier_blobs では anti-hub の 62% が外れ点になる（それ以外の点は 4%）。hubness が強いデータほど影響が大きい（N10 の歪度: hier 1.98 > density 1.09 > digits/pollen 0.8）。
4. **仕組み（力の分解、hier_blobs のエポック 700）。** 外れ点が受ける正味の力は内向きだが、他の点より弱い（−0.013 vs −0.038）。
   - 「誰かの近傍 j として引かれる」力が 1/3（−0.009 vs −0.021）。anti-hub の定義そのもの。
   - anchor としての hard negative の押し出しが 2 倍（+0.045 vs +0.020）。
   - 押し出されているというより、学習後半にクラスタの芯が縮む（中心からの距離 3.5 → 0.6）中で**取り残される**。
   - kNN 関係の非対称性が原因で、t-SNE は点ごとの帯域幅（perplexity 較正）でこれを打ち消している。

効かなかった対策: hard positive（遠くにいる真の近傍を優先）、hard negative の順位重み付け（trustworthiness 型）、片側 hard negative（侵入点 m を動かさない）、最適化手法の変更。
効果があった対策: **小さい K だけ局所スケーリングした順位を使う**（`local_scaling=10, local_scaling_kmax=30`、Zelnik-Manor & Perona 2004 の d/√(σ_i σ_j)）。
全 K に局所スケーリングをかけると外れ点は消えるが、pollen の距離相関が 0.86 → −0.02 に崩れる。

### blob での局所差（R_NX@10 で t-SNE に負ける）

- **hier_blobs: 原因は hard negative と γ の配分。** K≈10 の帯域プロファイル（k0=10）で目的関数を揃えても、hard negative があると ScaleRank は**自分の目的関数で t-SNE に負ける**（0.0425 vs 0.0364）。hard negative が目的関数そのものを歪めている。hard=0、予算 4 倍（per_point=128, 2000 エポック）なら R_NX@10 0.333（t-SNE 0.344）、目的関数も t-SNE より低い（0.0332）。
- **density_blobs: 代理の不一致が残る。** 同じ条件で目的関数は t-SNE より低い（0.084 vs 0.102）のに R_NX@10 は 0.33 vs 0.41。所属 AUC と R_NX のずれがまだある。
- **γ=1 は設計上 K>10 に重みを割く。** digits では帯域 k0=10 で R_NX@10 0.599 と t-SNE（0.583）を上回る。局所差の一部は「どのスケールを守るか」の選択の結果。

### hard negative のジレンマ

hard negative は digits のような多様体的データでは必須（R_NX@10 0.44 → 0.54）だが、hubness の強い高次元ガウス的データでは外れ点を作り目的関数を歪める。「2 次元では避けられない侵入」まで押し返していることが本質で、データ依存。

### 8 データでの比較（3 seed 平均、`drbench run` 済み）

| 変種 | 外れ点 | R_NX@10 | AUC | 距離相関 |
|---|---|---|---|---|
| A 現行（hard=0.3） | 16.4% | 0.499 | 0.565 | 0.816 |
| B hard=0 | 9.3% | 0.468 | 0.518 | 0.831 |
| Q 局所スケーリング K≤30 | 11.3% | 0.500 | 0.558 | 0.826 |
| R Q + hard=0.15 | 9.8% | 0.496 | 0.552 | 0.834 |

調整に使っていない 4 データ（s_curve, usoskin, kolodziejczyk, buettner）でも同じ傾向（R: 外れ点 16.5% → 10.9%、R_NX@10 −0.011、距離相関 +0.015）。
**緩和にはなるが解決ではない**（t-SNE は 1% 未満）。既定値は据え置き、オプションとして残した。

### 次の候補

- hard negative の代わりに、目的関数を precision@K に近い形（上位 K の境界にだけ効く重み）へ直接変える。データ依存のノブを減らせる可能性。
- 正例側の非対称性を直す: t-SNE のように点ごとの帯域で「近傍として引かれる量」を均す（anti-hub にも十分な引力）。
